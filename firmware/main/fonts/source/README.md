# Thai font sources

Sarabun Medium and SemiBold are vendored from the official Google Fonts
repository, downloaded 2026-10-23:

- https://raw.githubusercontent.com/google/fonts/main/ofl/sarabun/Sarabun-Medium.ttf
- https://raw.githubusercontent.com/google/fonts/main/ofl/sarabun/Sarabun-SemiBold.ttf

SIL Open Font License 1.1; see [../Sarabun-OFL.txt](../Sarabun-OFL.txt).
The generated C headers record the exact SHA256 of each source. These source
files are authoring inputs and are not linked into firmware.

From the repository root, regenerate with:

```sh
python3 scripts/export_thai_fonts.py
python3 scripts/export_thai_fonts.py --check
```

Reproduction environment: Python 3, Pillow 11.3.0, FreeType 2.13.3,
fontTools 4.60.2, HarfBuzz `hb-shape` 14.2.1 (offline authoring only).
Raster output depends on the FreeType version; `--check`
compares every generated byte and validates mark coverage and placement.

The 12px and 14px Medium faces preserve the established body sizes while using
individual FreeType advances instead of fixed tracking. The 18px SemiBold face
provides prominent Thai text with an 11px visible consonant body. All three
cover U+0E01–0E3A, U+0E3F–0E5B, the existing U+F700–F719 shaping variants,
U+F71A/B descenderless bases and U+F720–F765 contextual tone variants.

The exporter asks offline HarfBuzz to select actual source GSUB glyphs and
GPOS positions for each above/tone/base class. It crops their actual FreeType
masks and packs 4bpp pixels. Tall vowels use narrow outlines, stacked tones
use compact outlines, and E4D+tone ligatures include the above dot. The
firmware shaper selects by combining context and uses descenderless U+0E0D/U+0E10
bases before below vowels. Marks retain zero advance; identical bitmaps are
shared. No HarfBuzz or new runtime shaping library is linked into firmware.
Kerning remains disabled. Source positions are rounded to whole pixels.

Line metrics include the worst-case stacked and descender combinations, not
only the visible consonant body. The 12/14/18px line metrics are respectively
23/5, 26/6 and 33/8 (line height/baseline). Position labels by their measured
visible glyph bounds, and copy
both metrics to the corresponding Latin primary font when wiring its fallback.

Additional weight-corrected primary fonts use the same SemiBold source:

- `ct_font_ui_16`: all printable ASCII, degree, and the full Thai/contextual
  PUA set in one primary face; line height31/baseline8.
- `ct_font_ui_18`: the same complete mixed coverage for prominent page headers;
  line height33/baseline8.
- `ct_font_numeric_24`: space, digits, `+-.%`; line height19/baseline1.
- `ct_font_numeric_48`: the same numeric set; line height40/baseline3.

Numeric faces use a sparse cmap for the15 allowed codepoints. The ASCII space
has positive advance and zero ink dimensions in each face. The same exporter
and `--check` reproduce all seven outputs. Existing Thai12/14/18 output bytes
were retained when these additive faces were introduced.
